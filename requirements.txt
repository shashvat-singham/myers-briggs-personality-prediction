# IMPORTANT -- the ML pins are not arbitrary. models/*.joblib were serialised
# with scikit-learn 0.23.0 (verifiable: the pickles carry _sklearn_version).

# internal attributes changed in 1.0. scikit-learn 0.23.2 is the newest release
# that both loads these artifacts and ships a manylinux wheel, and its newest
# supported interpreter is CPython 3.8 -- hence python:3.8-slim in the
# Dockerfile. Retraining the four classifiers is the only way off this floor;
# see DEPLOYMENT.md ("Modernising the ML stack").
